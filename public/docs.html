API docs

TheDrunkBots Pay Check API proxies Paytm merchant status. It does not invent success. If Paytm has not recorded the order yet, you get a retryable status — never a fake TXN_SUCCESS.

Bot integration

PAYMENT_API_URL = os.environ.get(
    "PAYMENT_API_URL",
    "https://YOUR-HOST/"
)
# Bot calls: GET {PAYMENT_API_URL}?mid={PAYTM_MID}&oid={order_id}
# Expects JSON keys: STATUS, ORDERID, TXNAMOUNT, TXNID, BANKTXNID, TXNDATE

Endpoints

GET /?mid={MID}&oid={ORDER_ID}

Bot-compatible root.

GET /api?mid={MID}&oid={ORDER_ID}

Preferred API path. Also accepts id, orderId, ORDERID.

POST /api/verify

JSON body: { mid, oid } or { MID, ORDERID }.

GET /api/health

Liveness probe.

Success response

Always HTTP 200 so the bot never dies on a 404. Read STATUS, not the status code.
